## What you should look after while ordering
The PCB thickness should be 0.8mm. This will make perfect contact with the Gameboy if the PCB is within a cartridge casing.

You should order with ENIG (electroless nickel immersion gold) plating. While the cartridge will work with HASL you will getter contact with ENIG and it is less prone to wearing down.
